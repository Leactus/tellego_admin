Roles y permisos

Paquete de roles disponible para todos los negocios. Puedes editar el nombre y los permisos de los roles del sistema (Encargado, Cajero/a, Cocinero/a, Mesero/a, Repartidor) — el cambio se ve para todos a la vez, así que úsalo solo para corregir el paquete base; no se pueden borrar. Un rol nuevo que crees acá también se agrega al paquete y queda disponible para todo negocio, nuevo o existente — ese sí se puede borrar después. Si en cambio necesitas un rol a medida de un solo negocio (sin afectar a los demás), eso se hace desde el detalle de ese negocio (pestaña "Roles y permisos").
